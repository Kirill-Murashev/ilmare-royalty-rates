# ilmare-royalty-rates

[English version → README.en.md](README.en.md)

Расчётные скрипты справочника **«Справочник ставок роялти по отраслям ОКВЭД2 (метод распределения
прибыли лицензиата)»**, издание 2026.1 («Ilmarë»). Здесь только код, которым из открытой
бухгалтерской отчётности российских компаний получены статистика рентабельности и ставки
справочника, и сценарии, которые проверяют эти числа отдельным, независимо написанным расчётом.
Цель репозитория — чтобы любой читатель мог убедиться: числа справочника не нарисованы, а
пересчитываются из открытых данных.

Справочник: <https://app.digitalpm.info>. Авторы — Н. Р. Киршина, К. А. Мурашев.

## Метод одним абзацем

Ставка роялти `R = M × S`: `M` — операционная рентабельность продаж (строка 2200 / строка 2110
отчёта о финансовых результатах) компаний отрасли, `S` — доля, которую лицензиат отдаёт
лицензиару. Для каждого года, раздела, класса, подкласса и группы ОКВЭД2 берутся компании
после шести фильтров (Ф1–Ф5, Ф7; номер Ф6 зарезервирован) — выручка, чистые активы и капитал больше нуля,
исключение устойчиво убыточных, только коммерческие организации, распознанный код ОКВЭД2 —
считаются квартили по правилу п. 4 ст. 105.8 НК РФ и 95-процентные доверительные интервалы по
порядковым статистикам; по ширине интервала ячейке присваивается класс точности. База — верхний
квартиль `Q3` («успешный лицензиат»); долю `S` задают четыре бета-распределения (ступени ценности
объекта интеллектуальной собственности), а распределение ставки получается методом Монте-Карло
(100 000 розыгрышей, фиксированное зерно, одни и те же розыгрыши для всех ячеек и лет). Полное
описание — в разделах методологии справочника (§§ 3–8).

## Что в репозитории

```
ilmare_edition/           пакет расчёта
  load.py                 чтение одного года RFSD и фильтры Ф1–Ф7 (DuckDB)
  okved.py                справочник ОКВЭД2 и нормализация кодов RFSD
  stats.py                квартили НК, доверительные интервалы, классы точности
  marts.py                сборка витрин (parquet) и манифеста с контрольными суммами
  royalty.py              модель долей и Монте-Карло
  replace.py              замена модели долей в готовых витринах без пересчёта
  calibration.py          сверка с внешними ставками (команда calibrate)
  crosscheck.py           карта сверки с независимым пересчётом (команда crosscheck)
  marts_io.py             проверка и чтение каталога витрин
  data/share_model_v2.json   модель долей, принятая для издания 2026.1
  data/share_model_v1.json   прежняя модель; только история, для новых сборок отклоняется
independent-check/        независимый пересчёт (см. ниже)
tests/                    тесты на синтетических данных
```

## Установка

Нужен Python 3.12 или новее.

```sh
python -m venv .venv && . .venv/bin/activate
pip install -e '.[test]'          # duckdb 1.5.6, numpy 2.5.4; pytest, ruff
pip install -e '.[independent-check]'   # scipy 1.16.3 — только для независимого пересчёта
```

Версии зависимостей закреплены точно: побайтное совпадение parquet-файлов зависит от версии DuckDB.

## Входные данные

### 1. RFSD (бухгалтерская отчётность)

Открытая база **Russian Financial Statements Database**, версия 3.1.0 от 2026-09-02, Hugging Face:
<https://huggingface.co/datasets/irlspbru/RFSD>. Загрузчик читает файл за год **без** каких-либо
дополнительных колонок: используются только `inn`, `okved`, `okopf`, `simplified` и строки
`line_1300`, `line_1530`, `line_2110`, `line_2200`, `line_2300`, `line_2330`, `line_2400`.

Скачать отчётность 2011–2025 (около 6 ГБ на диске):

```sh
pip install 'huggingface_hub[cli]'
hf download irlspbru/RFSD --repo-type dataset \
  --revision ca3665997c977ba8ad01cf93c3e2a74ce7fe9c05 \
  --include 'RFSD/year=*/part-0.parquet' --local-dir rfsd
```

Ревизия `ca3665997c…` — коммит «Update to 3.1.0» (2026-09-02); следующий коммит правит только
README. Получится каталог `rfsd/RFSD/year=2011/part-0.parquet` … `year=2025/part-0.parquet`.
Шаблон имени файла — параметр `--file-pattern` (по умолчанию `RFSD/year={year}/part-0.parquet`,
путь отсчитывается от `--data-root`). Другая раскладка файлов, например по одному файлу на год
с другим именем, задаётся этим же параметром.

Для отбора Ф4 (исключение устойчиво убыточных компаний) загрузчик дополнительно читает файлы
двух предыдущих лет по тому же шаблону; для 2011 и 2012 годов их нет, и фильтр там не применяется
(см. методологию, § 5).

### 2. Справочник ОКВЭД2

Файл открытых данных Росстата, набор **7708234640-okvedva** («Общероссийский классификатор видов
экономической деятельности (ОКВЭД2)»), редакция от 2026-10-01:
<https://rosstat.gov.ru/opendata/7708234640-okvedva>, файл
`data-20261001T1110-structure-20180402T1704.csv` (464 582 байта,
SHA-256 `8e2bfae03a0f75b5cc71b2bb6e58063df4a415e64819059541fef05b2618d5be`).

```sh
curl -O https://rosstat.gov.ru/opendata/7708234640-okvedva/data-20261001T1110-structure-20180402T1704.csv
sha256sum data-20261001T1110-structure-20180402T1704.csv
```

Сайт Росстата использует сертификат, выпущенный российским удостоверяющим центром; если системное
хранилище его не знает, добавьте корневой сертификат Минцифры
(<https://gu-st.ru/content/lending/russian_trusted_root_ca_pem.crt>) и проверьте цепочку.
Формат файла: UTF-8, без заголовка, разделитель `;`, три поля — раздел, код, наименование; у
строки раздела код пробельный.

**Сам файл в репозиторий не включён.** Росстат публикует набор на условиях «Типовых условий
использования общедоступной информации в форме открытых данных» (<https://data.gov.ru/information-usage>),
собственной лицензии у набора нет. Полный текст условий мы автоматически прочитать не смогли, поэтому
перераспространять файл не стали: скачайте его с сайта Росстата и сверьте хеш.

## Воспроизвести витрины издания 2026.1

```sh
python -m ilmare_edition build-marts \
  --data-root rfsd \
  --okved-ref data-20261001T1110-structure-20180402T1704.csv \
  --out marts-2026.1 --edition 2026.1 \
  --years 2011-2025 --seed 20261017 --draws 100000 \
  --threads 3 --memory-limit 3GB
```

`--years` — годы отчётности; ставки имеют год на единицу больше (отчётность 2025 → ставки 2026).
Выходной каталог должен отсутствовать или быть пустым. Расчёт идёт по одному году и рассчитан на
лимит памяти 3 ГБ. Результат: шесть parquet-файлов (`cells`, `royalty`, `qgrid`, `sizes`, `funnel`,
`okved_names`), `share_model.json`, `manifest.json` (версия, параметры, размер и SHA-256 всех
прочитанных файлов) и `SHA256SUMS`. Подробности — в справке `python -m ilmare_edition build-marts -h`.

Витрины издания 2026.1 собраны тем же кодом расчёта до его выделения в этот репозиторий. Хеши ниже —
ожидаемые; подтверждение побайтного совпадения прогоном публичного кода будет опубликовано отдельно
(тег репозитория). Совпадение ожидается при тех же входных файлах и версиях зависимостей:

## Что проверяет карта сверки

Команда `crosscheck` сравнивает значения независимого пересчёта (CSV) с готовыми витринами и пишет
карту сверки `crosscheck.json`: по каждой проверке — значение издания, независимое значение,
допуск, итог. Для издания 2026.1 карта содержит **6 350 проверок по 74 ячейкам, расхождений 0**:

- 666 проверок значений ячеек (число компаний `n`, медиана, `Q1`, `Q3`, границы доверительных
  интервалов медианы и `Q3`, взвешенная рентабельность) для ставок 2012, 2013, 2019 и 2026 годов —
  допуск `n` равен нулю, остальных значений — `1e-12`;
- 5 684 проверки квантилей ставки (P5, P10, P25, P50, P75, P90, P95 для каждой ступени и базы);
  допуск — не менее 0,01 п. п. и не менее четырёх стандартных ошибок оценки Монте-Карло.

Ячейки выбраны по фиксированному зерну, по всем уровням (общий, разделы, классы, подклассы,
группы) и включают разделы K и L, а также ячейки без опубликованной ставки.

## Независимый пересчёт

Каталог `independent-check/` — четыре сценария, **написанные отдельно от кода издания**: по тексту
методологии, а не по `ilmare_edition`. Они не импортируют пакет, реализуют фильтры, нормализацию
ОКВЭД2, квартили НК и доверительные интервалы заново (чистый Python и SQL), а квантили ставки
находят не розыгрышем, а численным интегрированием по функции распределения. Совпадение двух
реализаций — доказательство того, что код делает ровно то, что написано в методологии. Порядок
запуска — в [independent-check/README.md](independent-check/README.md).

## Сверка с внешними ставками

Команда `calibrate` сопоставляет ставки из судебных актов, договоров франшизы, литературы и
зарубежной статистики с витринами и получает контрольные множители. Она читает три CSV с
разделителем `;` (формат — константа `COLUMNS` в `ilmare_edition/calibration.py`). **Сами наборы
в репозиторий не входят** (см. ниже), поэтому в публичном виде команда демонстрируется на
синтетических данных в `tests/test_calibration.py`.

## Чего в репозитории нет и почему

- **Выгрузка Elbereth по делам.** Результаты анализа судебных актов собраны в отдельной базе, права
  на которую не покрываются лицензией справочника.
- **Данные BVR и Markables.** Они принадлежат сторонним поставщикам; права на их
  перераспространение у авторов справочника не получены.
- **Наборы внешних ставок (российские и зарубежные).** Строки взяты из каталогов франшиз и
  судебных актов; права на строки не проверены.
- **Справочник ОКВЭД2** — см. выше: не перераспространяется, скачивается у Росстата.
- **Данные RFSD и готовые витрины.** RFSD скачивается с Hugging Face по лицензии CC BY 4.0;
  витрины воспроизводятся командой выше.
- **Генератор книги** (вёрстка LaTeX, шаблоны текста, рисунки, XLSX) и **калькулятор** — это не
  расчёт, а оформление и сервис; их нет.

## Тесты

```sh
python -m pytest -q
python -m ruff check .
```

Тесты используют только синтетические данные (до сотни строк за год). `tests/test_independent_check.py`
прогоняет полный путь «витрины → независимый пересчёт → карта сверки» на синтетике; он пропускается,
если не установлен scipy.
